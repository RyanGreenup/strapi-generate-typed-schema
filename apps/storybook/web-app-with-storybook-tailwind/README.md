# Strapi OpenAPI Spec Generator — Storybook with Tailwind CSS

SolidJS app built with Vite and Tailwind CSS, with Storybook component examples,
autogenerated documentation, accessibility checks, and browser interaction
tests.

## Development

Install workspace dependencies from the repository root with `pnpm install`,
then run commands in this app:

```sh
cd apps/storybook/web-app-with-storybook-tailwind
pnpm run dev
```

The app runs on <http://localhost:3000>. Start Storybook separately with
`pnpm run storybook` at <http://localhost:6006>. If another variant is already
running, choose a different port with `pnpm run dev -- --port 3001` or
`pnpm run storybook -- --port 6007`.

## Scripts

Run these commands from `apps/storybook/web-app-with-storybook-tailwind`:

- `pnpm run dev`: start the Vite development server.
- `pnpm run build`: build the app into `dist`.
- `pnpm run serve`: preview the production build.
- `pnpm run storybook`: start the component explorer.
- `pnpm run build-storybook`: build the explorer into `storybook-static`.
- `pnpm run check-types`: check TypeScript with the shared Solid/Vite preset.
- `pnpm run lint`: run type-aware linting and check formatting.
- `pnpm run format`: format files with the shared formatter configuration.
- `pnpm run fix`: apply suggested lint fixes.

## Stories and browser tests

The Button, Header, and Page examples live in `src/stories`; the Page login
story includes an interaction test. `Configure.mdx` contains Storybook setup
guides and bundled example assets.

Install Chromium before running the Vitest browser project:

```sh
pnpm exec playwright install chromium
pnpm exec vitest run --project storybook
```

On Linux, Playwright may also require system libraries installed with
`pnpm exec playwright install --with-deps chromium`.

The Vite config uses `@storybook/addon-vitest` and headless Playwright Chromium.
Accessibility violations appear in the test UI without failing tests; change
`a11y.test` in `.storybook/preview.tsx` to `"error"` to fail on violations.

## Tailwind CSS

`src/index.css` imports Tailwind CSS and defines the example font theme.
`@tailwindcss/vite` processes utility classes through Vite, while
`.storybook/preview.tsx` imports the same stylesheet for the stories.

See the [Storybook documentation](https://storybook.js.org/docs) for component
stories, documentation, and testing configuration.
